2026-08-03 公司筆電 v1.9.17 基本資料欄位裁切修正
----------------------------------------------------------------
1. 根本原因為 QGridLayout 在右側可用高度不足時壓縮 Preferred 欄位容器，但內部 Fixed 高度輸入框不會同步縮小，超出容器的部分因此被裁切。
2. 基本資料表單及各欄位容器改用 Minimum 垂直尺寸策略，禁止低於內容所需高度。
3. 表單 GridLayout 使用 SetMinimumSize，確保標籤、輸入框、間距及備註欄的最低高度納入計算。
4. 新增 basicDataScrollArea；空間不足時只讓表單區垂直捲動，水平捲動維持關閉。
5. 管理摘要及儲存、清空、刪除按鈕位於捲動區外，不會因表單較長而無法操作。
6. 新增特大字體與 760 px 高度回歸測試，逐欄確認輸入元件不會超出容器被裁切。
7. 未修改 PostgreSQL schema、FastAPI、資料內容、權限或手機 Web。

2026-07-30 家中伺服器 v1.9.27／公司筆電 v1.9.12 關係人身分證
----------------------------------------------------------------
1. PostgreSQL schema 11 在 contacts 新增 external_id TEXT；欄位設計與 owners.external_id 一致，沒有新增平行 hash 或 last4 結構。
2. 關係人身分證使用地主既有 make_fernet、encrypt_value、decrypt_value 及 mask_identity_text，共用相同資料金鑰與 enc:v1 密文格式。
3. 新增、修改 API 支援 external_id；清單、搜尋、重複提示與明細一律回傳 A123*****9 遮蔽格式。
4. 新增具 Editor／Admin 權限的身分證揭露端點；Viewer 不得取得完整值。
5. 未修改既有身分證時，客戶端傳送 None，伺服器保留原始密文；只有輸入新完整值時才重新加密。
6. 共用台灣身分證驗證會去除前後空白、轉大寫、檢查字母與性別碼格式及檢查碼，錯誤資料無法儲存。
7. Windows 關係人新增／編輯視窗新增身分證欄位及「顯示／隱藏」按鈕；既有資料預設遮蔽，顯示時才呼叫揭露 API。
8. migration rollback 只移除 contacts.external_id 與 schema 11 紀錄，不修改地主或其他正式資料表。
9. 新增加密不含明文、遮蔽、揭露權限、保留舊密文、格式驗證、API、桌面 UI、migration 與 rollback 測試。

2026-07-30 家中伺服器 v1.9.26／公司筆電 v1.9.11 土地 QTreeView checkbox 點擊修正
----------------------------------------------------------------
1. 建立唯一 CHECK_COLUMN，TreeModel 的 flags 同時保留 ItemIsUserCheckable、ItemIsEnabled 與 ItemIsSelectable。
2. CheckStateRole 回傳 Qt.Checked、Qt.Unchecked 或 Qt.PartiallyChecked；父節點依 ownership 子節點計算半選狀態。
3. 修正 QStyledItemDelegate 寫入 setData() 時傳入原生整數 0／2，舊程式只與 PySide6 enum 比較而永遠判定為未勾選的根本問題。
4. 新增 set_node_checked() 統一土地父節點與 ownership 子節點的勾選、取消勾選、callback 及 dataChanged。
5. checkbox callback 與右鍵勾選共用 set_checked_record_id()，保留既有 checked_record_ids 與批次功能。
6. 標籤 TagPillDelegate 只以 setItemDelegateForColumn() 安裝於標籤欄，沒有 editorEvent() 攔截 checkbox。
7. eventFilter 不攔截滑鼠；checkbox 欄 clicked 路徑直接返回，不做第二次反向切換。
8. checkbox 點擊不呼叫 refresh_records()、setModel()、beginResetModel() 或 endResetModel()，只局部發出 dataChanged。
9. 新增真實滑鼠點擊、勾選／取消、父節點半選、Delegate 欄位隔離及不刷新 Model 測試。
10. 未修改 PostgreSQL schema、FastAPI 資料格式、手機 Web 或 LINE Bot。

- 額外補上第一欄點擊事件處理。
- 使用者點擊第一欄時，直接切換該筆資料的勾選狀態。

4. 修正結果：
- 選取格恢復正常，可穩定勾選與取消勾選。

- 在載入 openpyxl 前補齊 openpyxl 會使用的 NumPy 型別別名
- 若環境沒有 NumPy，仍維持原本不依賴 NumPy 的處理方式

4. 測試：
- 新增「打包環境 NumPy 缺少 short 別名」回歸測試

四十二、v1.1.3 進階搜尋同欄多值

- SQLite 候選查詢會為每個欄位建立 OR 群組，再以 AND 串接不同欄位
- 解密後敏感欄位比對與 FastAPI 資料篩選套用相同規則
- 進階搜尋視窗的說明與欄位提示會直接顯示可用分隔符號
