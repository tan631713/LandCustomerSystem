土地資料系統－NetBird 私人 VPN 連線說明
==========================================

用途
----
讓 iPhone 與公司筆電不必和家中主機在同一個 Wi-Fi，也能安全連回土地資料系統。
資料仍放在你自己的 Windows 筆電與 PostgreSQL，不會搬到 NetBird。

首次設定（Windows）
------------------
1. 安裝 NetBird Windows 用戶端。
2. 執行 setup_netbird_vpn.bat，以瀏覽器登入並授權這台筆電。
3. 在 allow_netbird_vpn_firewall.bat 上按右鍵，選擇「以系統管理員身分執行」。
4. 已安裝過 iPhone HTTPS 憑證者可沿用；若瀏覽器警告不受信任，再執行 install_iphone_certificate.bat。

首次設定（iPhone）
-----------------
1. 到 App Store 搜尋並安裝官方「NetBird」App。
2. 使用與 Windows 相同的帳號登入。
3. 允許 iOS 加入 VPN 設定，並按 Connect。
4. 若尚未安裝本系統 CA 憑證，先在 Windows 執行 install_iphone_certificate.bat，依畫面網址下載並信任憑證。

每次外出使用
------------
1. 筆電保持開機、PostgreSQL 正常，並確認 Windows NetBird 顯示 Connected。
2. 執行 start_mobile_server_vpn.bat。
3. iPhone 開啟 NetBird 並 Connect；手機可用 4G、5G、任意 Wi-Fi 或個人熱點。
4. Safari 輸入啟動視窗顯示的 https://100.x.x.x:8732/mobile/。

公司筆電完整桌面程式請使用獨立 CompanyLaptopClient ZIP，詳見 `公司筆電遠端使用說明.txt`；公司筆電不執行本檔案中的家中伺服器啟動器。

安全限制
--------
- Windows 防火牆只允許同一個 NetBird 帳號所屬的私人 /16 網段連到 8732、8733。
- PostgreSQL 5432 維持只允許本機，不對 VPN 或網際網路開放。
- 不要在分享器設定連接埠轉發，也不要把 API 直接公開到網際網路。
- NetBird Free 目前適合個人或小團隊，限 5 位使用者、100 台裝置；超過官方限制才需要改用付費方案。

停止使用
--------
關閉 start_mobile_server_vpn.bat 的視窗即可停止 API。若暫時不用私人 VPN，也可在 NetBird App 按 Disconnect。
