正式啟動方式
1. 家中主機：只執行「啟動家中伺服器.bat」，視窗保持開啟。
2. 公司筆電：使用獨立 CompanyLaptopClient ZIP，執行 start_company_laptop_desktop.bat。
3. iPhone 行動版：NetBird Connect 後以 Safari 開啟家中主機的 /mobile/ 網址。
4. iPhone 第一次連線：依「伺服器使用說明.txt」開啟 8733 公開憑證頁並完成信任。

重要提醒
- 「啟動家中伺服器.bat」是伺服器包唯一正式入口；不要開啟 _server_support 或 LandCustomerServer 內部檔案。
- 啟動器會自動檢查 NetBird、PostgreSQL 服務、私人 VPN 防火牆、資料庫連線、HTTPS 與備份；首次設定才會要求 UAC 或 PostgreSQL 管理員密碼。
- 請完整保留整個伺服器資料夾，不要只複製 LandCustomerServer.exe。

資料與備份
- PostgreSQL 是 Windows 與 iPhone 唯一共用的正式資料來源；舊 SQLite 不參與同步。
- API 或手機伺服器啟動時會檢查每日 PostgreSQL 壓縮備份。
- 啟動器每 24 小時自動建立備份；備份包含 PostgreSQL dump、manifest 與納管附件。
- 備份預設放在 %LOCALAPPDATA%\LandCustomerSystem\postgres-backups，保留 90 天、最多 30 份且至少保留 3 份。

- 公司筆電透過 NetBird HTTPS 使用修改歷史、自訂欄位、快速範本、注意名單、操作記錄、座標、重複資料忽略及附件完整性檢查，資料直接存回家中 PostgreSQL。
- 開放批次修改、批次自訂欄位、Excel 匯入設定檔、報表範本、智慧重複資料檢查、地圖、勾選刪除與全部刪除。
- 備份還原、使用者／密碼管理、既有資料加密等伺服器維護功能仍須在家中主機操作，避免公司端誤觸。

v1.4.2 必要軟體確認安裝
- 啟動前判斷 NetBird、PostgreSQL Server 與 pg_dump 是否已安裝。
- 缺少軟體時先列出名稱與用途，必須由使用者輸入 Y／Yes／是才會安裝；拒絕時不修改系統並停止啟動。
- NetBird 由官方 winget 套件靜默安裝；PostgreSQL 使用官方互動安裝程式，由使用者自行設定管理密碼。
- 缺少 winget 時不會嘗試繞過，會指示安裝 Microsoft「應用程式安裝程式」。
- 診斷檔記錄缺少項目、winget 狀態與使用者決定，不記錄密碼、DSN 或權杖。

v1.4.1 單一伺服器入口修正
- 伺服器包最外層只保留「啟動家中伺服器.bat」，刪除所有舊版與重複啟動檔。
- 修正 NetBird 防火牆來源範圍，由錯誤的單一 `/16` 改為官方 CGNAT `100.64.0.0/10`，不同 NetBird IP 區段的手機與公司筆電可正常連線。
- 新增不含帳密的 home-server-diagnostics.json，明確指出 NetBird、服務、防火牆、資料庫、憑證、備份或連接埠問題。
- 自動啟動只提供公開 CA 的 8733 安裝頁，主伺服器停止時一併關閉。
- 伺服器封裝不再包含桌面客戶端，並拒絕資料庫、備份、附件、DSN 或私鑰。

v1.4.0 家中伺服器／公司桌面客戶端
- 家中主機固定為唯一 PostgreSQL、FastAPI、附件與備份來源。
- 家中伺服器入口已改為一鍵預檢與自動修復，不必再分別執行 NetBird、防火牆、PostgreSQL 設定及 HTTPS 啟動檔。
- 新增公司筆電完整桌面客戶端 ZIP；不含 PostgreSQL、Server、正式資料、帳密、備份或私鑰。
- 公司桌面 EXE 由封裝設定強制連家中 NetBird HTTPS，直接點 EXE 也不會切回本機 SQLite 正式模式。
- 公司端只建立 `desktop-client-settings.db` 保存介面偏好，資料表只有 `app_settings`，不含地主或土地。
- iPhone 維持 Safari／主畫面瀏覽器版，與公司筆電同時讀寫家中 PostgreSQL。
- 公司啟動器新增 NetBird、TCP、HTTPS 憑證、API backend 與 schema 完整預檢，並產生不含帳密的診斷報告。
- 公司介面開放遠端安全的批量新增、匯出、進階搜尋、品質、儀表板、案件、標籤、附件、聯絡與追蹤工具；本機限定功能保持灰色。
- 安全查詢遇到短暫網路錯誤會重試一次，寫入操作不自動重送。

v1.3.0 NetBird 私人 VPN 外出連線
- Windows 與 iPhone 可透過同一個 NetBird 帳號安全互連，不必位於同一 Wi-Fi，也不需要路由器連接埠轉發。
- 新增 NetBird 自動安裝／登入、VPN HTTPS 啟動器與專用防火牆設定。
- HTTPS 憑證自動納入並優先顯示 NetBird `100.x` IP。
- 舊版曾只允許單一 `/16`；v1.4.1 已修正為完整 `100.64.0.0/10`。
- PostgreSQL 5432 維持只監聽本機；實機 HTTPS 由 127.0.0.1 與 NetBird IP 連線都回傳 200，正式資料為 267 筆。

v1.2.1 手機熱點連線修正
- 防火牆輔助檔支援 Windows 私人與公用網路，但只允許同一區域網路子網路連入 8732/8733。
- 切換 Wi-Fi／手機熱點時會重新偵測可用 IP，更新 HTTPS 憑證並列出所有手機網址。
- PostgreSQL 5432 仍只供本機使用，沒有對手機、區網或網際網路開放。

v1.2.0 PostgreSQL 正式版與 iPhone 行動版

- 新增 iPhone PWA：首頁統計、地主搜尋、土地搜尋、持分明細、聯絡／拜訪紀錄與追蹤提醒。
- 新增區域網路 HTTPS 憑證建立、iPhone 公開憑證安裝服務與私人網路防火牆輔助檔。
- 新增 PostgreSQL + 附件自動／手動壓縮備份與備份驗證。
- 手機頁面不快取 API 或敏感資料；登入 token 只保存在目前 App／Safari 工作階段。

v1.1.3 進階搜尋同欄多值
- 同一欄可用「、」、「，」或半形逗號分隔多個值，符合其中任一值即可。
- 不同欄位之間仍必須全部符合，例如「地區：桃園區」加「地段：中路、中路段」。
- SQLite 候選篩選、解密後比對與 API 篩選採用相同規則。
- 進階搜尋視窗新增清楚的輸入提示，原始資料內容不會被修改。

v1.1.2 進階搜尋多條件修正
- 可連續填寫地區、地段、地號、姓名等多個欄位，系統會要求每個已填條件都符合。
- 在欄位內按 Enter 會移到下一欄；最後一欄才會直接套用。
- 套用後會清除舊快速搜尋與快速篩選，避免看不見的舊條件干擾結果。
- 條件比對會忽略資料中的半形與全形空白，但不會修改原始資料。

- Excel 匯入、一般 Excel 匯出、品質檢查 Excel 匯出都會先套用 openpyxl/NumPy 相容處理。
- 新增回歸測試，避免打包環境缺少 NumPy 型別別名時再次造成 Excel 處理失敗。

v1.0.8 優化
- 資料品質檢查結果新增「確認忽略此問題」。
- 已確認的相同品質提醒會保存到系統設定，下次檢查自動隱藏。
- 視窗會顯示已隱藏的已確認問題數量。
- 新增「清除已忽略」，可讓已確認問題下次重新顯示。

v1.0.7 優化
- 資料品質檢查結果新增「複製目前清單」。
- 複製內容包含標題列與資料 ID、程度、類型、問題、建議處理。
- 複製格式可直接貼到 Excel 自動分欄，也可貼到訊息中交辦。
- 會依目前篩選結果複製，方便只交辦重要問題或疑似重複資料。

v1.0.6 優化
- 資料品質檢查結果新增篩選。
- 可只看全部問題、重要、提醒、疑似重複、格式異常、姓名空白、地號缺漏、分母為 0。
- 匯出 Excel 會依目前篩選結果輸出，方便只交辦特定類型問題。

v1.0.5 優化
- 資料品質檢查結果新增「匯出 Excel」。
- 匯出內容包含資料 ID、程度、類型、問題與建議處理。
- 匯出的 `.xlsx` 可用於列印、交給他人修正或留存稽核紀錄。

v1.0.4 優化
- 資料品質檢查結果可雙擊問題列，直接載入對應資料到右側表單。
- 新增「前往選取資料」按鈕，可從檢查結果快速定位修正。
- 定位後狀態列會提示已載入的資料 ID。

v1.0.3 優化
- 工具選單新增「資料品質檢查」。
- 可一鍵檢查姓名空白、地號缺漏、面積/公告現值格式異常、分子/分母格式異常、分母為 0。
- 新增疑似重複檢查：同土地識別、同登記次序、同姓名/身分證會列為提醒。
- 檢查結果以表格顯示程度、類型、問題與建議處理。

v1.0.2 優化
- 設定選單新增「使用說明」。
- 使用說明包含快速開始、批量新增、Excel 匯入匯出、備份還原、搜尋選取與常見狀況。
- 批量新增說明加入實際範例、分隔符號、身分證空白與序號手動輸入提醒。

v1.0.1 優化
- 登入失敗、登入鎖定、固定 admin 帳號提示改成更清楚的使用者說明。
- 備份狀態、手動備份、自動安全備份失敗提示加入建議處理方式。
- 還原備份流程提示更清楚說明覆蓋風險、安全備份與重開需求。
- 儲存資料與修改密碼失敗時會同時顯示建議處理與技術訊息。
