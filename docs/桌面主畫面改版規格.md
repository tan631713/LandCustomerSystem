## 3. 字型

Qt 桌面程式不能用網路字型。這次**不下載、不打包字型檔**（要使用者同意才做，見 §9）。

- 介面字型：`Microsoft JhengHei UI`，退回 `Microsoft JhengHei`。延用既有的 `apply_font_size`，字級設定不變。
- 標題與地號（區段標題「土地標示部」、右上大地號）：先用 `QFontDatabase` 檢查有沒有 `Noto Serif TC`；有就用它（粗體 700），沒有就用 `Microsoft JhengHei UI` 粗體。寫成 `customer_theme.heading_font(point_size)`。
- 數字欄位（面積、公告現值、持分、總現值）靠右對齊即可，不另換字型。
