## 沒驗證到的地方

- **防火牆實際狀態沒查到。** 這台筆電有憑證資料夾，但 `C:\Program Files\NetBird\netbird.exe` 不存在，所以它不是設定完整的家中伺服器，或 NetBird 裝在別處。真正的家中伺服器上有沒有那兩條規則，要在那台機器上執行 `home_server_preflight.ps1 -Mode Check` 才知道。
- **其他防火牆規則可能繞過限制。** 如果 Windows 另外留有 Python 或 uvicorn 的「允許所有私人網路」規則，區網其他裝置也連得進 8732。這點無法從程式碼確認。
- **加入主畫面、GPS、拍照上傳都沒在手機上實測。** 外勤驗收清單（`外勤模式使用與驗收說明.txt`）目前也沒逐項打勾。

## 程式碼裡看到的不一致

- `app.js` 的 `MOBILE_ASSET_VERSION` 是 33，但 `index.html` 引用 `app.js?v=31`，Service Worker 快取名也是 `land-customer-mobile-v31`。因為是網路優先，目前沒有實際影響，但數字已經對不上，而且測試把 31 寫死了（`tests/test_customer_api.py:178`、`:233`）。
