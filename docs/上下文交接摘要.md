## 1. 核心專案

**土地資料系統**：一個人（加少數同事）管理土地與地主資料（約 696 筆土地、2,236 筆持分）、聯絡與追蹤紀錄、手機外勤拜訪。資料敏感（姓名、身分證、地址用 Fernet 加密；檢視者角色身分證遮罩）。

| 部分 | 技術 |
|---|---|
| 家中伺服器 | FastAPI + PostgreSQL 18，PyInstaller 打包成 exe；控制台是原生 tkinter + Pillow（刻意不用 customtkinter，啟動要 8–12 秒） |
| 公司筆電客戶端 | PySide6（Qt）桌面程式，經 NetBird VPN + HTTPS 連家中伺服器；也保留單機版（SQLite） |
| 手機 | `customer_mobile_web/`，PWA，由伺服器提供（`/mobile/`） |

分支 `codex/server-v1.9.27-client-v1.9.12`，遠端 `origin` = GitHub `tan631713/LandCustomerSystem`。目前版本：**伺服器 v1.9.43**、**客戶端 v1.9.85**、**資料庫結構 v14**、手機資源版號 33。
