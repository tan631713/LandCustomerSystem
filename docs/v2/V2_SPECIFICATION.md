# v2.0 規格凍結

## 1. 正式架構

```text
公司 Windows 桌面 ─┐
iPhone PWA ─────────┼─ NetBird / HTTPS / 私人 CA ─ FastAPI v2 ─ PostgreSQL
LINE Bot ───────────┘                                      ├─ 附件庫
                                                         ├─ 稽核與排程
                                                         └─ 備份與回復
```

PostgreSQL 是唯一正式資料來源。附件原檔只存家中主機附件庫並隨完整備份保存。客戶端只可保存介面偏好、短期安全快取及工作階段，不可建立第二份正式地主資料。

## 2. v2.0 必做範圍

### API 與平台

- `/api/v2` 版本化介面、能力協商與最低客戶端版本。
- v1 過渡相容、棄用標頭與過舊客戶端寫入阻擋。
- 統一錯誤格式、錯誤代碼、Request ID 與脫敏診斷。
- 游標分頁、穩定排序、欄位白名單與查詢筆數上限。
- 資料列版本及樂觀鎖，避免不同裝置互相覆蓋。
- 背景工作、重試、執行結果與健康儀表板。

### 業務流程

- 地主、土地、持分、案件、附件與追蹤的全域搜尋。
- 案件狀態、負責人、期限、下一步、任務、檢查清單與版本化工作流。
- 追蹤、案件、任務、逾期及完成回條共用通知中心。
- 批次操作預覽、差異、批次編號與可復原紀錄。
- 附件縮圖、分類、說明、雜湊、完整性掃描及備份核對。
- 登入、查詢、修改、匯入、備份、還原與管理操作的安全稽核。

### 跨端

- 桌面完整管理；iPhone 現場查詢、聯絡／拜訪、追蹤、案件下一步與附件。
- LINE Bot 保持最小權限，以唯讀查詢與受控通知為主。
- 桌面管理 LINE 使用者名稱、備註、綁定、停用與權限。
- 桌面、手機與 LINE 顯示相同的更新時間、狀態及完成回條。

### 升級

- 一鍵升級前檢查、正式備份、隔離複本遷移、自動核對、冒煙測試及回復包。
- 家中主機、公司筆電、iPhone、LINE Bot 五個真實工作情境驗收。

## 3. v2.0 應做範圍

- 重複資料人工審查工作台。
- 報表排程與通知摘要。
- API、資料庫及背景工作的效能指標。
- 自訂工作流狀態與轉移規則版本化。

應做項目若影響 14 週正式切換，可延到 v2.1，但不得破壞必做契約。

## 4. 明確非目標

- 完整離線正式資料同步與離線衝突合併。
- 專業 GIS 地籍套疊與編輯。
- OCR 自動匯入正式欄位。
- AI 自動判定地主意願或成交機率。
- 公開網際網路直接部署、付費雲端或 PostgreSQL 對外開放。
- 即時多人聊天室及多人共同編輯游標。

## 5. 資料與隱私規則

- 姓名、身分證、地址、備註及出訪內容維持加密儲存。
- Viewer、手機與 LINE 的身分證只顯示前四碼及最後一碼。
- 稽核可記錄實體 ID、動作類型、結果、耗時及錯誤代碼，不記查詢文字或敏感欄位原值。
- 所有下載、縮圖、匯出及附件操作必須先驗證工作階段與資料範圍。
- 密碼、DSN、資料金鑰與私人 CA 金鑰不得進入 Git、診斷包或發行包。

## 6. 版本凍結

| 元件 | v2 開發基線 | v2 正式最低版本政策 |
|---|---:|---|
| 家中伺服器 | v1.8.9 | v2.0.0 |
| 公司筆電 | v1.8.2 | v2.0.0 才可寫入 v2 功能 |
| iPhone PWA | v1.8.9 隨附 | 由 v2 伺服器自動更新 |
| LINE Bot | v0.30.0 | v2.0.0；舊版只讀過渡 |
| PostgreSQL schema | 7 | 12（由 8～12 逐版套用） |
| SQLite 相容 schema | 8 | 不再擴充正式業務功能 |

## 7. v2.0 完成定義

1. v1 保留功能全部通過回歸測試。
2. 五個真實工作情境可由任一允許端開始，其他端重新整理後立即看到一致結果。
3. 同一資料同時修改會回傳 409 衝突，不會靜默覆蓋。
4. 角色、欄位遮罩、資料範圍、匯出及附件權限沒有越權。
5. 完整備份可在隔離環境還原，筆數、關聯、附件 SHA-256、帳號及加密資料均通過。
6. 任一升級關卡失敗可退回 v1.8.9／v1.8.2／v0.30.0。
7. 正式包、操作說明、管理手冊、診斷方式、測試報告及版本台帳齊全。
