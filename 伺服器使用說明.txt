土地資料系統－家中主機伺服器 v1.9.22

本版新增地主關係人管理 API 與 PostgreSQL schema 9。第一次啟動會新增
contacts 與 owner_contact_relations，不修改既有地主、土地或持分資料表。
請先使用既有功能完成一次完整備份，再以新版伺服器包覆蓋程式檔並啟動。
========================================

建議的日常啟動方式：圖形控制台
------------------------------
伺服器資料夾根目錄與「啟動家中伺服器.bat」並列多了一個
LandCustomerServerConsole.exe，這是取代直接看 cmd 黑視窗的圖形控制台，
只負責啟動、監看與操作，不改任何伺服器邏輯、API 或資料。

- 一眼看狀態：最上方一列顏色＋文字（未啟動／啟動中／運作中／錯誤／運作中 · 資料庫尚無帳號）；
  啟動中會顯示「第 n/7 步」，錯誤會顯示問題摘要與下一步做法。
- 「啟動步驟」7 列燈號：完成（綠）、進行中（藍）、失敗（紅，附原因）、略過（褐，附原因，例如 24 小時內已有備份）、未執行（灰）。
- 按鈕取代手動操作：啟動、停止、重啟、立即備份、開啟備份資料夾、開啟手機網頁；不可用的按鈕會變淡。
- 連線資訊（手機網址、iPhone 憑證網址、CA 指紋、NetBird IP）都有「複製」按鈕，
  手機網址並附 QR Code，手機相機掃描即可開啟，不需要手動輸入網址；伺服器未運作時顯示「—」。
- 「管理」分頁提供三個只在本機執行、不經網路的功能：
  * 建立第一個管理員：資料庫完全沒有帳號時才能用，帳號名稱自訂（建議不要用 admin 這類容易猜到的名稱），
    不需要再手動放 .request 檔。
  * 管理員密碼恢復：從下拉選單挑要重設的管理員；驗證用帳號必須是另一個目前可登入的帳號，失敗時原密碼與資料都不會修改。
  * 匯入遷移包：先選檔，按「匯入並重新啟動」後輸入帳號密碼（資料庫完全沒有帳號時只需要單機版管理員帳密，
    匯入後這個帳號就是伺服器管理員，單機版其他帳號也會一併帶入）。匯入前會先做安全備份，「上次匯入」顯示最近一次成功的檔名與時間。
- 資料庫尚無帳號時，狀態列會直接出現「建立第一個管理員」與「匯入遷移包」兩個按鈕，並自動切到「管理」分頁；
  若資料夾內已有待匯入的遷移包，建立第一個管理員會停用，請先匯入。
- 關閉視窗只會縮到系統匣，伺服器不會因此停止；手機與公司筆電可以繼續連線。
  真的要停止伺服器，用視窗裡的「停止」按鈕，或系統匣右鍵選單裡的選項。
- 需要以系統管理員權限執行（與「啟動家中伺服器.bat」相同），雙擊即可，
  Windows 會照常詢問一次權限。
- 更新時請把三個檔一起換：LandCustomerServerConsole.exe、LandCustomerServer.exe，以及
  _server_support 資料夾內的 home_server_runtime.ps1。只換控制台會出現「找不到參數 NonInteractive」，
  或步驟燈號不會動。

雙擊 LandCustomerServerConsole.exe 開啟控制台，再按「啟動」即可，
效果與執行下面的舊版 .bat 完全相同（背後就是呼叫同一個
home_server_runtime.ps1）。

舊版純文字啟動方式（仍可使用）
------------------------------
只執行「啟動家中伺服器.bat」。不想用圖形控制台，或要在沒有畫面的情境
下啟動時，這個方式仍然完整保留，行為與之前完全一致。

若桌面程式顯示含「錯誤代碼」的 API 錯誤，請到
%LOCALAPPDATA%\LandCustomerSystem\logs\server-error.log
核對相同代碼；錯誤記錄會自動輪替，不需定期手動清除。

新版伺服器包的最外層只會有這一個 .bat 啟動檔與一個控制台 .exe；
不要進入 _server_support 或 LandCustomerServer 資料夾開啟內部檔案。

一鍵啟動會依序完成
------------------
1. 判斷 NetBird、PostgreSQL Server 與 pg_dump 是否已安裝。
2. 若有缺少，顯示軟體名稱與用途，詢問是否由系統協助安裝。
3. 只有輸入 Y／Yes／是才會透過 Windows winget 安裝；輸入 N 或其他內容會安全停止。
4. PostgreSQL 使用官方互動安裝程式，管理密碼由使用者自行設定，系統不會代填或保存。
5. 登入或確認 NetBird，並啟動 PostgreSQL Windows 服務。
6. 建立只允許 NetBird 100.64.0.0/10 的 8732、8733 防火牆規則。
7. 既有伺服器會先確認最近 24 小時內有 PostgreSQL 完整備份，再檢查或升級資料結構。
8. 若保存的專案連線密碼已失效，系統會要求 postgres 管理密碼修復專案帳號，再重新備份；修復或備份仍失敗才停止。
   v1.9.2 起，備份程式回報連線失敗不會再讓 PowerShell 提前中止，會正常進入此修復步驟。
   v1.9.3 起，資料庫結構說明中的分號不會被誤切為 SQL 指令，修復後可繼續建立備份。
9. 檢查 PostgreSQL 專案資料庫、HTTPS 憑證、公開 CA 頁與每日備份，再啟動正式伺服器。
10. 若偵測到舊版留下的 CUSTOMER_API_DATABASE_URL，正式伺服器會安全忽略它並使用 Windows DPAPI 保護的本機設定。
11. 自動套用 PostgreSQL 第 8 版資料結構；不需手動執行 SQL。

把單機資料搬到家中伺服器
----------------------------
1. 在單機資料所在筆電建立一個 `.lcs-migration.zip` 搬移包；建立過程使用 SQLite 一致性快照，不需要關閉後手動複製 customers.db。
2. 關閉家中伺服器視窗，將唯一一個 `.lcs-migration.zip` 放到「啟動家中伺服器.bat」旁。
3. 開啟唯一啟動檔、輸入 Y，依序輸入單機版帳號密碼及家中伺服器 admin 密碼。
4. 系統會確認家中業務資料庫為空、先建立 PostgreSQL 匯入前備份，再以伺服器共用金鑰重新加密並寫入資料。
5. 匯入交易內會核對每張資料表筆數與關聯孤兒；失敗會回滾。完成後再以手機及公司筆電確認資料。
6. 伺服器帳號、角色與已恢復的 admin 密碼均會保留；單機 users 不會覆蓋伺服器 users。
7. 若伺服器已有有效持分、案件、附件等正式業務資料，或套件損壞、重複匯入、單機含附件，此版會停止而不強行合併。
8. 若只是刪除測試資料後留下無持分的地主／土地、回收桶或操作歷史，不會誤擋首次搬移；孤立地主／土地會在同一交易清理，歷史紀錄保留。

忘記手機登入密碼
------------------
1. 若仍有已登入的單機版，先在「設定 → 使用者與權限」新增一個至少 10 字元密碼的帳號。
2. 使用帳號匯出工具產生 .lcs-account，將該檔案複製到「啟動家中伺服器.bat」旁。
3. 開啟唯一啟動檔並輸入 Y，接著在家中主機本地輸入新帳號密碼；輸入內容不會顯示或寫入檔案。
4. 系統會先證明新帳號能解密既有伺服器資料，再只新增該帳號；不會覆蓋地主、土地、持分或案件。
5. 手機登入測試成功後，刪除或離線保存 .lcs-account；該檔案不含明碼密碼，但仍應視為敏感檔案。

恢復 admin 密碼
----------------
1. 只有擁有家中主機檔案存取權時才能執行；不會從手機或公司筆電遠端開放此功能。
2. 將空白的 recover-admin-password.request 放在「啟動家中伺服器.bat」旁。
3. 開啟唯一啟動檔並輸入 Y，依序輸入目前可登入帳號、該帳號密碼及兩次新的 admin 密碼。
4. 系統會先驗證目前帳號能解開既有資料，再以同一資料金鑰安全包裝新的 admin 密碼；admin 不存在時會建立，存在時會重設。
5. 密碼錯誤、兩次新密碼不同或資料金鑰不符時會取消整個交易；成功後要求檔會自動刪除。

備份維護
--------
- 公司桌面「異地完整備份」填寫的是家中主機路徑，例如 E:\土地備份或已掛載 NAS，不是公司筆電路徑。
- 「還原備份」只接受家中備份清單，會先建立還原前安全備份並驗證 ZIP、database.dump 與 SHA-256。
- 還原成功後所有手機與筆電登入都會失效，請重新登入。

如果缺少軟體且 Windows 找不到 winget，請先從 Microsoft Store 安裝「應用程式安裝程式」，再重新執行唯一啟動檔。

視窗顯示「HTTPS 伺服器執行中」後請保持開啟。關閉視窗即停止手機與公司筆電連線。

iPhone
------
1. 安裝官方 NetBird App，使用與家中主機相同的帳號登入並 Connect。
2. 第一次使用時，以 Safari 開啟伺服器視窗顯示的 http://100.x.x.x:8733/。
3. 下載公開 CA 憑證並完成描述檔安裝。
4. 到「設定 → 一般 → 關於本機 → 憑證信任設定」，開啟完整信任。
5. 再開啟伺服器視窗顯示的 https://100.x.x.x:8732/mobile/。

公司筆電
--------
使用獨立的 CompanyLaptopClient ZIP，執行 start_company_laptop_desktop.bat。公司筆電不安裝 PostgreSQL，也不執行家中伺服器檔案。

故障診斷
--------
若啟動失敗，請傳回：
%LOCALAPPDATA%\LandCustomerSystem\home-server-diagnostics.json

診斷檔只記錄檢查階段、狀態、NetBird IP、服務狀態與網址，不包含 PostgreSQL 密碼、DSN、登入密碼或存取權杖。

安全提醒
--------
- 不要在路由器開放 8732、8733 或 5432。
- PostgreSQL 5432 只供家中主機本機使用。
- 伺服器包不含正式資料庫、備份、附件、DPAPI 連線設定或 HTTPS 私鑰。
