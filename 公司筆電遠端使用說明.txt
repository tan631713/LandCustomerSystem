土地資料系統－公司筆電完整桌面程式
====================================

公司筆電客戶端版本：v1.8.6

版本相容提醒：家中伺服器 v1.9.15 搭配公司筆電 v1.8.6，可從桌面選取多筆地主、加入共用今日行程並設定為優先拜訪。

正式架構
--------
家中主機是唯一伺服器與唯一 PostgreSQL 資料來源。
公司筆電只安裝完整桌面客戶端，不安裝 PostgreSQL、不啟動 FastAPI，也不保存第二份正式資料。
iPhone 只使用 Safari／主畫面瀏覽器版。

家中主機
--------
1. 保持 Windows、PostgreSQL 與 NetBird 開機連線，停用自動休眠。
2. 只需執行「啟動家中伺服器.bat」；程式會自動完成 NetBird、PostgreSQL 服務、防火牆、資料庫、HTTPS 與備份檢查。
3. 首次設定可能會要求 NetBird 瀏覽器登入、Windows 管理員授權或 PostgreSQL 管理員密碼。
4. 視窗不可關閉；畫面會顯示手機網址與家中 NetBird IP。

公司筆電首次設定
----------------
1. 解壓縮完整的 CompanyLaptopClient ZIP，不可只複製 EXE。
2. 執行 start_company_laptop_desktop.bat；若尚未安裝或登入 NetBird，啟動器會在同一流程引導完成。
3. 程式第一次開啟時，直接輸入家中伺服器畫面顯示的 NetBird IP。
4. 客戶端會從該 IP 的 8733 取得公開 CA，顯示 SHA-256 指紋；確認與家中伺服器視窗相同後選擇「是」。
5. 程式會保存 IP 與此主機的公開 CA；不需要修改 home_server_ip.txt，也不需要安裝 PostgreSQL 或執行伺服器防火牆設定。

公司筆電每次使用
----------------
1. 確認公司網路可以上網，NetBird 顯示 Connected。
2. 執行 start_company_laptop_desktop.bat。
3. 程式會使用上次保存的 IP 檢查 HTTPS 憑證、PostgreSQL API 與資料結構，再開啟完整 Windows 桌面介面。
4. 使用土地資料系統帳號登入；資料會立即讀寫家中 PostgreSQL。
5. IP 改變時，開啟「設定 ＞ 伺服器連線設定」輸入新 IP，測試成功後重新啟動程式即可。

公司桌面可用功能
------------------
- 同地號批量新增、Excel 匯入、Excel／Word 匯出。
- 進階搜尋、常用條件、資料品質檢查、資料統計儀表板與系統健康檢查。
- 案件、標籤、附件、聯絡紀錄、追蹤提醒與批量標籤。
- 字體、欄位顯示、勾選狀態與唯讀模式等裝置偏好。
- 所有登入帳號都能查看經路徑遮罩的家中備份健康狀態；User 不會再被誤顯示為備份異常。
- 回收桶、使用者管理、既有資料加密、家中備份還原與異地備份；需要管理員的選單會對 User 停用，維護操作實際在家中伺服器執行，不會在公司筆電建立第二份正式資料。
- 還原備份限管理員，必須選家中清單中的有效備份並完整輸入「還原家中伺服器」；完成後程式關閉並要求重新登入。

iPhone
------
1. NetBird 使用同一帳號登入並 Connect。
2. Safari 開啟 https://家中NetBird-IP:8732/mobile/。
3. iPhone 不需安裝 Windows 桌面程式。

安全與限制
----------
- 公司筆電客戶端包不預先夾帶任何主機的 CA；伺服器 IP 由使用者輸入，公開 CA 從該家中主機取得並確認後保存在目前公司筆電。
- 公開 CA 只用於驗證家中 HTTPS 伺服器，不是私鑰；下載公開 CA 不會傳送地主、土地、帳號或密碼。
- 家中主機關機、休眠、斷網、NetBird 中斷或伺服器視窗關閉時，公司筆電與手機都無法使用。
- 不要在家中路由器開放 5432、8732 或 8733。
- 若家中主機重新加入 NetBird 而 IP 改變，請在「設定 ＞ 伺服器連線設定」輸入新 IP；家中主機會在啟動時準備對應的 HTTPS 憑證。
- 若啟動失敗，請查看 `%LOCALAPPDATA%\LandCustomerSystem\client-network-diagnostics.json`。此檔只包含連線狀態、版本與筆數，不包含密碼或登入權杖。
- 安全的 GET 查詢遇到短暫斷線會自動重試一次；新增、修改、刪除不會自動重送，避免重複寫入。
