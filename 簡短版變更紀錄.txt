土地資料系統 簡短版變更紀錄
================================

2026-07-16 v1.5.0 公司桌面程式功能補齊
- 遠端可用修改歷史、自訂欄位、快速範本、注意名單、操作記錄、座標、重複資料忽略及附件完整性檢查。
- 開放批次修改、匯入／報表範本、智慧重複檢查、地圖及刪除操作，資料都寫回家中 PostgreSQL。
- 備份還原、帳號密碼與資料加密仍限家中主機，避免公司端誤觸。

2026-07-16 v1.4.2 必要軟體確認安裝
- 啟動前自動判斷 NetBird、PostgreSQL Server 與 pg_dump 是否已安裝。
- 缺少時顯示名稱及用途，使用者輸入 Y／Yes／是後才透過 winget 安裝；拒絕時安全停止。
- PostgreSQL 採互動安裝，管理密碼由使用者自行設定且不會保存。
- 診斷檔新增缺少軟體、winget 可用狀態及安裝決定，不含敏感資料。

2026-07-16 v1.4.1 單一伺服器入口修正
- 伺服器包最外層只保留「啟動家中伺服器.bat」，舊版 API、手機、VPN、測試與設定啟動檔全部移除。
- 一鍵流程自動處理 NetBird 登入、PostgreSQL 服務、防火牆、資料庫設定、HTTPS、公開憑證頁、備份與正式伺服器。
- 修正防火牆範圍為 NetBird 官方 `100.64.0.0/10`，不再誤擋不同 `100.x` 區段的手機或公司筆電。
- 啟動失敗會產生不含帳密的 home-server-diagnostics.json。
- 伺服器封裝不含桌面客戶端、資料庫、備份、附件、DSN 或私鑰。

2026-07-14 v1.4.0 家中伺服器／公司桌面客戶端
- 家中主機是唯一 PostgreSQL、FastAPI、附件與備份伺服器。
- 當時以 `start_home_server_vpn.bat` 作為一鍵入口；v1.4.1 已由中文唯一入口取代。
- 新增公司筆電完整桌面客戶端 ZIP，透過 NetBird HTTPS 讀寫家中資料，不含或啟動本機 PostgreSQL／Server。
- 客戶端封裝會強制桌面 EXE 使用家中 API，避免直接點 EXE 誤建第二份正式資料。
- 公司端只保存介面偏好資料庫，沒有 customers、地主、土地或附件資料表。
- iPhone 維持 Safari 瀏覽器版；手機與公司桌面可同時操作家中 PostgreSQL。
- 公司客戶端新增完整 HTTPS API 預檢、無敏感資料診斷報告、安全 GET 重試與封裝資料排除檢查。
- 公司介面開放遠端可用的批量新增、匯出、進階搜尋、品質檢查、儀表板、案件、標籤、附件、聯絡與追蹤工具。
- 全系統 164 項自動測試全部通過，並完成本機與 NetBird HTTPS 實機健康檢查。

2026-07-14 v1.3.0 NetBird 私人 VPN 外出連線
- Windows 與 iPhone 登入同一個 NetBird 帳號後，可跨不同 Wi-Fi／4G／5G 安全連回自架系統。
- 新增 NetBird 自動安裝登入、VPN HTTPS 啟動器、專用防火牆與完整操作說明。
- HTTPS 憑證會偵測並優先顯示 NetBird `100.x` IP。
- 舊版防火牆曾限制單一 `/16`；v1.4.1 已修正為完整 NetBird `100.64.0.0/10`。
- 實機確認 NetBird IP HTTPS API／行動頁皆回傳 HTTP 200，PostgreSQL 正式資料 267 筆。
- 全系統 150 項自動測試全部通過。

2026-07-14 v1.2.1 手機熱點連線修正
- 防火牆規則支援手機熱點常見的 Windows 公用網路，但遠端來源限制為同一子網路。
- 切換網路後會重新偵測 IP、更新 HTTPS 憑證並列出全部可用手機網址。
- PostgreSQL 5432 維持本機限定，不因手機熱點支援而開放。
- 全系統 149 項自動測試全部通過。

2026-07-14 v1.2.0 PostgreSQL 正式版與 iPhone 行動版
- 不再做 SQLite／PostgreSQL 比對；現有 PostgreSQL 直接成為正式共用資料來源。
- Windows 正式入口改為 PostgreSQL API 模式，登入只使用 API 帳號。
- 新增可加入 iPhone 主畫面的地主開發助手：地主／土地搜尋、持分明細、聯絡紀錄與追蹤提醒。
- 新增自建區網 HTTPS、iPhone CA 憑證安裝頁及私人網路防火牆輔助檔。
- 新增 PostgreSQL + 附件壓縮備份、每日啟動前檢查、保留清理與 pg_restore 結構驗證。
- PostgreSQL 健康檢查實機確認 267 筆持分資料，HTTPS 手機頁與安全標頭正常。
- 全系統 148 項自動測試全部通過。

2026-07-14 自架手機同步第一階段
- 新增 FastAPI，沿用現有帳號、角色權限與加密資料，可查地主、土地、持分及追蹤。
- 手機 API 可新增聯絡紀錄與下次追蹤，不需再手動匯出 Excel。
- 新增 SQLite／PostgreSQL 資料來源介面，現有 SQLite 仍保持正式來源。
- 新增正規化 PostgreSQL schema 與預設唯讀、需明確確認才寫入的遷移工具。
- API 預設只允許本機連線；LAN 模式需明確開啟，正式外出連線必須使用 HTTPS 或私人 VPN。
- 修正舊版 contact_logs 欄位未升級造成 API 查詢 500；啟動時會先備份並安全轉換舊資料。
- 安裝本機 PostgreSQL 18.4，新增專案資料庫一次設定工具；管理密碼不落地，專案連線資料由 Windows DPAPI 加密保存。
- PostgreSQL API 改為必須明確使用 `--postgres` 才切換，平常仍安全使用 SQLite。
- 新增視窗式只讀盤點與平行移轉流程，寫入前自動備份 SQLite，完成後自動核對 PostgreSQL 筆數。
- 已完成 121 位地主、94 筆土地、156 筆持分、4 筆聯絡紀錄及 2 筆追蹤提醒的平行移轉；PostgreSQL API 實機檢查正常。
- PostgreSQL 5432 只監聽 localhost，手機只透過 FastAPI 存取資料。
- 全系統 116 項自動測試全部通過。
- 修正 PostgreSQL API 批次檔可能一閃即逝；改為固定 Python 路徑、啟動前健康檢查，結束或失敗時都保留視窗訊息。

1. 系統初始方向
- 由原本想做 SQLite 客戶資料系統，整理成土地資料管理系統。
- 使用 SQLite 作為本機資料庫。

2. 欄位與資料結構調整
- 移除 Email 欄位。
- 原本的公司欄位改為 ID 使用。
- 主要欄位整理為：
  區、段、登記次序、地號、面積、公告現值、權利範圍、總公告現值、
  所有權人、ID、地址、登記原因、備註。
- 後續再調整為：
  地區、地段、序號、地號、面積/m2、公告現值、分子、分母、坪數、
  總現值/元、姓名、身分證、地址、原因、備註、出訪記錄。

3. UI 與操作調整
- 改成桌面 UI 介面。
- 右側表單版面改回接近一開始的樣式。
- 新增右鍵選單刪除客戶/資料功能。
- 新增勾選方格，可多選清除資料。
- 新增全部清除功能，並加上 3 次確認。

4. 自動計算與格式化
- 總公告現值改為自動公式計算。
- 總公告現值取消小數點。
- 公告現值與總公告現值加上千分位。
- 坪數顯示到小數點後兩位。

5. Excel 匯入
- 新增 `.xlsx` 匯入功能。
- 改善中文欄位與合併儲存格匯入。
- 匯入時可自動判斷表頭、補欄位、帶入公式。

6. 登入與加密
- 新增登入帳號驗證。
- 單人使用版本帳號固定為 `admin`。
- 登入密碼同時作為資料解密密碼。
- 敏感資料改為加密儲存。
- 新增「加密既有資料」功能。
- 新增修改密碼功能，放在「設定」內。

7. 身分證顯示控制
- 新增顯示/隱藏身分證按鈕。
- 隱藏格式為：保留前 3 碼與最後 1 碼，中間改成 `*`。

8. 備份與還原
- 新增自動備份 `customers.db`。
- 啟動時每日自動備份。
- 匯入、批次刪除、全部清除、加密既有資料、修改密碼前自動備份。
- 設定內新增「開啟備份資料夾」。
- 設定內新增「還原備份」。
- 還原前會先自動備份目前資料。

9. 效能與 UI 升級
- 原本 Tkinter 版本在筆電大量資料滾動時有明顯頓挫。
- 後續改為 PySide6 版桌面 UI。
- 保留原功能與大致版面。
- 表格改為較順的 Qt 表格模型。
- 加入分批載入，改善大量資料刷新速度。

10. 篩選與排序
- 新增欄位篩選。
- 新增欄位排序。
- 可選擇不同欄位做查找與新到舊/舊到新排序。
- 新增進階搜尋。
- 新增常用搜尋條件儲存與載入。

11. 選取格修正

12. 表格記憶與匯出
- 記住欄寬、隱藏欄位與欄位順序。
- 匯出 Excel 會保留目前畫面中的顯示欄位與欄位順序。

13. 批次修改與匯入報表
- 新增勾選多筆後批次修改功能。
