土地資料系統 簡短版變更紀錄
================================

2026-08-03 公司筆電 v1.9.17 基本資料欄位裁切修正

- 儲存、清空與刪除按鈕固定保留，特大字體與較矮視窗亦可正常操作。

2026-08-03 公司筆電 v1.9.16 基本資料欄位顯示修正

2026-07-30 家中伺服器 v1.9.26／公司筆電 v1.9.11 土地 checkbox 點擊修正
- 統一 checkbox 欄位常數、flags、CheckStateRole 與父子節點勾選邏輯。
- 修正 Qt 原生 Delegate 傳入整數 0／2 時被誤判，畫面可直接勾選及取消勾選。

2026-07-30 家中伺服器 v1.9.26／公司筆電 v1.9.10 土地清單自動展開修正
- 使用者展開集合與搜尋暫時展開集合完全分離，程式還原期間的訊號不會污染使用者狀態。
- 儲存資料、單筆／批量標籤、關係人、附件、聯絡紀錄、管理刷新與排序均維持原展開／收合狀態。
- 搜尋清除後恢復使用者原狀；新增土地預設收合，刪除土地會清除失效 ID。
- 未修改 PostgreSQL schema、FastAPI 資料格式或手機 Web。

2026-07-30 家中伺服器 v1.9.26／公司筆電 v1.9.9 多標籤建立修正
- 新增標籤不再沿用第一個標籤 ID，第二個標籤不會覆蓋第一個。
- 「新增標籤」會清除 ID、選取、名稱與顏色；只有選取既有標籤才進入編輯模式。
- POST／PUT 分流與 A、B 建立及 A 編輯均有自動化測試；PostgreSQL schema 與土地樹狀狀態保存不變。

2026-07-30 家中伺服器 v1.9.26／公司筆電 v1.9.8 標籤操作展開修正
- 單筆、批量及標籤名稱／顏色管理均改用原 TreeModel 局部更新。
- 標籤 API 操作前保存展開、收合、選取及捲動狀態，完成後不再觸發搜尋全部展開。
- 標籤文字與顏色即時更新，已收合土地保持收合；伺服器與 PostgreSQL schema 不變。

2026-07-30 家中伺服器 v1.9.26／公司筆電 v1.9.7 儲存後群組展開修正
- 修改現有地主、土地或 ownership 後沿用原 TreeModel，只更新節點並發出 dataChanged。
- 排序值改變但群組成員相同時不再 Model Reset；原本展開與收合、選取及捲動狀態均保留。
- 搜尋自動展開與儲存刷新分離，搜尋中的儲存不再把全部群組展開；伺服器與 PostgreSQL schema 不變。

2026-07-30 v1.9.26／公司筆電 v1.9.5 標籤顏色修正
